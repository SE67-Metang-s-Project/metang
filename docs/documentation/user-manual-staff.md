# คู่มือการใช้งานระบบ Me_Tang สำหรับอาจารย์ที่ปรึกษา เจ้าหน้าที่ และผู้บริหาร

ระบบที่ครอบคลุม: Me_Tang 0.1.0
ฉบับเอกสาร: 0.1 ฉบับร่าง (Jira NAT-237)
วันที่: 2026-09-29

> ภาพหน้าจอทั้งหมดถ่ายจากระบบทดสอบที่ใช้ข้อมูลสมมติ ชื่อ รหัส เลขบัญชี และสลิปในภาพไม่ใช่ข้อมูลจริง
> คู่มือสำหรับผู้ดูแลระบบระดับสูง (SuperAdmin) แยกอยู่ในเอกสารอีกฉบับ

## 1. เกี่ยวกับคู่มือนี้

คู่มือนี้อธิบายงานในระบบ Me_Tang ของผู้ใช้ 3 บทบาท

| บทบาท | งานหลัก | หัวข้อ |
|---|---|---|
| อาจารย์ที่ปรึกษา | พิจารณาคำร้องของนักศึกษาในความดูแล ดูประวัติของนักศึกษา | 4 |
| เจ้าหน้าที่ (Admin) | ตรวจสอบเอกสารและวงเงิน โอนเงินให้นักศึกษา ตรวจสอบสลิปชำระเงินคืน | 5 |
| ผู้บริหาร | อนุมัติคำร้องขั้นสุดท้าย ดูภาพรวมการเงินและข้อมูลนักศึกษา | 6 |

ข้อความ **ตัวหนา** คือชื่อปุ่ม ชื่อช่อง หรือข้อความบนหน้าจอ ตรงตามที่ระบบแสดง

### 1.1 ลำดับการพิจารณาคำร้อง

1. นักศึกษายื่นคำร้อง สถานะ **รออาจารย์พิจารณา**
2. อาจารย์ที่ปรึกษาพิจารณา เมื่ออนุมัติ สถานะเป็น **รอเจ้าหน้าที่ตรวจสอบ**
3. เจ้าหน้าที่ตรวจสอบเอกสารและวงเงิน เมื่อส่งพิจารณา สถานะเป็น **รอผู้บริหารอนุมัติ**
4. ผู้บริหารอนุมัติ สถานะเป็น **รอเบิกจ่ายเงิน**
5. เจ้าหน้าที่โอนเงินและแนบสลิป สถานะเป็น **โอนเงินแล้ว**
6. นักศึกษาชำระคืนเป็นงวด เจ้าหน้าที่ตรวจสอบสลิปทุกงวด เมื่อชำระครบ สถานะเป็น **เสร็จสิ้น**

การส่งกลับแก้ไขในแต่ละขั้น:

| ผู้ส่งกลับ | คำร้องกลับไปที่ |
|---|---|
| อาจารย์ที่ปรึกษา | นักศึกษา |
| เจ้าหน้าที่ | นักศึกษา |
| ผู้บริหาร | เจ้าหน้าที่ เพื่อปรับลดวงเงิน คำร้องไม่กลับไปที่นักศึกษา |

ทุกการตัดสินใจต้องมีความเห็นหรือเหตุผล ระบบไม่ส่งคำร้องต่อหากช่องความเห็นว่าง

### 1.2 ความหมายของสถานะคำร้อง

| สถานะบนหน้าจอเจ้าหน้าที่ | ความหมาย |
|---|---|
| รออาจารย์พิจารณา (ในหน้าของอาจารย์แสดงเป็น **รอพิจารณา**) | รออาจารย์ที่ปรึกษาพิจารณา |
| รอเจ้าหน้าที่ตรวจสอบ | รอเจ้าหน้าที่ตรวจสอบเอกสารและวงเงิน |
| รอผู้บริหารอนุมัติ | รอผู้บริหารอนุมัติขั้นสุดท้าย |
| รอเบิกจ่ายเงิน | ผู้บริหารอนุมัติแล้ว รอเจ้าหน้าที่โอนเงิน |
| โอนเงินแล้ว | เจ้าหน้าที่โอนเงินแล้ว นักศึกษาอยู่ระหว่างชำระคืน |
| เสร็จสิ้น | นักศึกษาชำระครบแล้ว |
| ส่งกลับแก้ไข | คำร้องอยู่ที่นักศึกษาเพื่อแก้ไข |
| ไม่อนุมัติ | ผู้พิจารณาไม่อนุมัติคำร้อง |
| ยกเลิกคำร้อง | นักศึกษายกเลิกคำร้อง |

## 2. เข้าสู่ระบบและเมนู

**ขั้นตอน:**

1. เปิดเว็บไซต์ระบบ
2. คลิก **เข้าสู่ระบบด้วย CMU Account** แล้วลงชื่อเข้าใช้ด้วย CMU Account ในหน้าของ Microsoft

   ![หน้าเข้าสู่ระบบ](images/user-manual-student/student-01-login.png)

3. ระบบแสดงหน้าหลักของบทบาทที่ได้รับสิทธิ์ บทบาทกำหนดโดยผู้ดูแลระบบระดับสูง
4. คลิกปุ่มเมนู (☰) ที่มุมซ้ายบนเพื่อเปิดเมนู คลิกชื่อเมนูเพื่อไปยังหน้านั้น

![เมนูของอาจารย์ที่ปรึกษา](images/user-manual-staff/advisor-00-menu.png)

| บทบาท | เมนู |
|---|---|
| อาจารย์ที่ปรึกษา | **หน้าหลัก**, **คำร้องรอพิจารณา โดยอาจารย์ที่ปรึกษา**, **นักศึกษาในความดูแล** |
| เจ้าหน้าที่ | **หน้าหลัก**, **คำร้องรอตรวจสอบ**, **เบิกจ่ายหนี้**, **ตรวจสอบสลิปชำระเงิน** |
| ผู้บริหาร | **หน้าหลัก**, **คำร้องรอพิจารณา โดยอาจารย์ที่ปรึกษา**, **คำร้องรอพิจารณา โดยผู้บริหาร**, **นักศึกษาในความดูแล** |

**ออกจากระบบ:** คลิกชื่อของท่านที่มุมขวาบน แล้วคลิก **ออกจากระบบ**

## 3. การแจ้งเตือนทาง LINE

เมื่อมีคำร้องรอท่านดำเนินการ ระบบส่งข้อความทาง LINE พร้อมเลขที่คำร้อง ชื่อนักศึกษา และจำนวนเงิน

| ข้อความ | ผู้รับ | หน้าที่ต้องเปิด |
|---|---|---|
| มีคำร้องใหม่รอการตรวจสอบ | อาจารย์ที่ปรึกษาของนักศึกษา | คำร้องรอพิจารณา โดยอาจารย์ที่ปรึกษา |
| มีคำร้องรอการพิจารณาจากเจ้าหน้าที่ | เจ้าหน้าที่ | คำร้องรอตรวจสอบ |
| มีคำร้องรอการอนุมัติจากผู้บริหาร | ผู้บริหาร | คำร้องรอพิจารณา โดยผู้บริหาร |
| มีคำร้องรอการโอนเงิน | เจ้าหน้าที่ | เบิกจ่ายหนี้ |

## 4. อาจารย์ที่ปรึกษา

### 4.1 หน้าหลัก

หน้าหลักแสดง **คำร้องรอพิจารณา • ในฐานะอาจารย์ที่ปรึกษา** และ **นักศึกษาในความดูแล** ล่าสุด
คลิก **ดูคำร้องทั้งหมด** หรือ **ดูรายชื่อทั้งหมด** เพื่อเปิดรายการเต็ม

![หน้าหลักของอาจารย์ที่ปรึกษา](images/user-manual-staff/advisor-01-dashboard.png)

### 4.2 พิจารณาคำร้อง

**วัตถุประสงค์:** อนุมัติ ส่งกลับแก้ไข หรือไม่อนุมัติคำร้องของนักศึกษาในความดูแล

**สิ่งที่ต้องมี:** คำร้องมีสถานะ **รอพิจารณา**

**ขั้นตอน:**

1. เปิดเมนู **คำร้องรอพิจารณา โดยอาจารย์ที่ปรึกษา** แท็บ **รอพิจารณา** แสดงคำร้องที่รอท่าน
   ค้นหาด้วยรหัสคำร้องหรือชื่อได้ที่ช่องค้นหา

   ![คำร้องรอพิจารณา](images/user-manual-staff/advisor-02-pending.png)

2. คลิก **ตรวจสอบ** ที่คำร้องที่ต้องการ ระบบแสดงหน้าต่าง **คำร้องรอพิจารณา**
3. ตรวจสอบ **ข้อมูลนักศึกษา**, **ข้อมูลการกู้ยืม**, **ตารางการชำระ**, **พฤติกรรมการชำระเงิน**
   และ **ติดตามสถานะคำร้อง** เลื่อนลงเพื่อดูข้อมูลทั้งหมด

   ![รายละเอียดคำร้อง](images/user-manual-staff/advisor-03-review-top.png)

   ![พฤติกรรมการชำระเงินและสถานะคำร้อง](images/user-manual-staff/advisor-04-review-bottom.png)

4. คลิกปุ่มผลการพิจารณา
   - **อนุมัติ**: ส่งคำร้องต่อให้เจ้าหน้าที่
   - **ส่งกลับแก้ไข**: ส่งคำร้องกลับให้นักศึกษาแก้ไข
   - **ไม่อนุมัติ**: ปิดคำร้อง นักศึกษาต้องยื่นคำร้องใหม่
5. กรอกความเห็นหรือเหตุผลในช่องที่ระบบแสดง ช่องนี้จำเป็นต้องกรอก ไม่เกิน 500 ตัวอักษร
   - อนุมัติ: **ความเห็นประกอบการพิจารณา**
   - ส่งกลับแก้ไข: **ระบุสิ่งที่ต้องการให้นักศึกษาแก้ไข**
   - ไม่อนุมัติ: **ระบุเหตุผลเพื่อแจ้งกลับให้นักศึกษาทราบ**
6. คลิก **ยืนยันอนุมัติ**, **ยืนยันส่งกลับแก้ไข** หรือ **ยืนยันไม่อนุมัติ** หากต้องการเปลี่ยนใจ คลิก **ยกเลิก**

   ![ยืนยันอนุมัติ](images/user-manual-staff/advisor-05-approve-confirm.png)

**ผลลัพธ์:** ระบบแสดง **ดำเนินการคำร้องเสร็จสิ้น** คลิก **เสร็จสิ้น** คำร้องออกจากแท็บ **รอพิจารณา**
นักศึกษาเห็นความเห็นของท่านในหน้าติดตามสถานะคำร้อง

![ดำเนินการคำร้องเสร็จสิ้น](images/user-manual-staff/advisor-06-done.png)

### 4.3 นักศึกษาในความดูแล

หน้านี้แสดงนักศึกษาทุกคนที่เคยส่งคำร้องให้ท่านพิจารณา พร้อม **สถานะคำร้องปัจจุบัน**,
**พฤติกรรมชำระเงิน**, **การกู้ยืมทั้งหมด** และ **หนี้คงเหลือ**

1. เปิดเมนู **นักศึกษาในความดูแล**
2. กรองด้วยแท็บ **ทั้งหมด**, **ชำระตรงเวลา** หรือ **เคยชำระล่าช้า** หรือเลือกระดับการศึกษา
3. คลิกชื่อนักศึกษาเพื่อดู **ประวัติหลักฐานการชำระเงิน**

![นักศึกษาในความดูแล](images/user-manual-staff/advisor-07-students.png)

![ประวัติหลักฐานการชำระเงินของนักศึกษา](images/user-manual-staff/advisor-08-student-detail.png)

## 5. เจ้าหน้าที่ (Admin)

### 5.1 หน้าหลัก

หน้าหลักแสดงงานที่รอเจ้าหน้าที่ 3 กลุ่ม: **คำร้องรอพิจารณา**, **รายการเบิกจ่าย** และ **ตรวจสอบสลิปชำระเงิน**
คลิก **ดูทั้งหมด →** เพื่อเปิดหน้าของงานนั้น

![หน้าหลักของเจ้าหน้าที่](images/user-manual-staff/admin-01-dashboard.png)

### 5.2 ตรวจสอบคำร้องและวงเงิน

**วัตถุประสงค์:** ตรวจสอบเอกสารและวงเงิน แล้วส่งคำร้องให้ผู้บริหาร ส่งกลับให้นักศึกษาแก้ไข หรือไม่อนุมัติ

**สิ่งที่ต้องมี:** คำร้องมีสถานะ **รอเจ้าหน้าที่ตรวจสอบ**

> **หมายเหตุ:** เมื่อเจ้าหน้าที่คนหนึ่งส่งคำร้องให้ผู้บริหารแล้ว คำร้องนั้นผูกกับเจ้าหน้าที่คนนั้น
> ถ้าผู้บริหารส่งกลับ คำร้องจะแสดงเฉพาะในรายการของเจ้าหน้าที่คนเดิม

**ขั้นตอน:**

1. เปิดเมนู **คำร้องรอตรวจสอบ**

   ![คำร้องรอตรวจสอบ](images/user-manual-staff/admin-02-pending.png)

2. คลิก **ตรวจสอบ** ที่คำร้องที่ต้องการ แล้วตรวจสอบข้อมูลในหน้าต่าง **คำร้องรอพิจารณา**
3. คลิก **ดาวน์โหลดแบบคำร้อง (PDF)** เพื่อดูหรือพิมพ์แบบคำร้อง

   ![รายละเอียดคำร้องสำหรับเจ้าหน้าที่](images/user-manual-staff/admin-03-review-top.png)

4. หากต้องการปรับลดวงเงิน:
   1. คลิก **ปรับวงเงิน** ข้าง **จำนวนเงินที่ขอกู้ยืม**
   2. กรอกวงเงินใหม่ วงเงินต้องมากกว่า 0 บาท และไม่เกินจำนวนที่นักศึกษาขอ
   3. คลิกปุ่มบันทึก (✓) ระบบแสดง **ปรับลดจาก ...** และคำนวณ **ตารางการชำระ** ใหม่

   ![ปรับวงเงิน](images/user-manual-staff/admin-04-adjust-amount.png)

5. คลิกปุ่มผลการพิจารณา
   - **ส่งพิจารณา**: ส่งคำร้องให้ผู้บริหาร พร้อมวงเงินที่ส่งพิจารณา
   - **ส่งกลับแก้ไข**: ส่งคำร้องกลับให้นักศึกษาแก้ไข
   - **ยกเลิกคำร้อง**: ไม่อนุมัติคำร้อง นักศึกษาเห็นสถานะ **ไม่อนุมัติโดยเจ้าหน้าที่**
6. กรอกความเห็นหรือเหตุผลในช่องที่ระบบแสดง ช่องนี้จำเป็นต้องกรอก
   หากปรับลดวงเงิน ให้ระบุเหตุผลของการปรับลดในช่องนี้
7. คลิก **ยืนยันส่งพิจารณา**, **ยืนยันส่งกลับแก้ไข** หรือ **ยืนยันยกเลิกคำร้อง**

   ![ส่งกลับแก้ไข](images/user-manual-staff/admin-05-return-confirm.png)

   ![ยืนยันส่งพิจารณา](images/user-manual-staff/admin-06-approve-confirm.png)

**ผลลัพธ์:** ระบบแสดง **ดำเนินการคำร้องเสร็จสิ้น** คำร้องที่ส่งพิจารณามีสถานะ **รอผู้บริหารอนุมัติ**

![ดำเนินการคำร้องเสร็จสิ้น](images/user-manual-staff/admin-07-done.png)

### 5.3 คำร้องที่ผู้บริหารส่งกลับ

ผู้บริหารส่งคำร้องกลับให้เจ้าหน้าที่เพื่อปรับลดวงเงินเท่านั้น
คำร้องแสดงป้าย **ผู้บริหารให้แก้ไข** และข้อความ **ผู้บริหารส่งกลับมาแก้ไข**

1. เปิดคำร้องจาก **คำร้องรอตรวจสอบ** แล้วอ่านความเห็นของผู้บริหารใน **ติดตามสถานะคำร้อง**
2. คลิก **ปรับวงเงิน** แล้วกรอกวงเงินที่น้อยกว่าวงเงินเดิม ปุ่ม **ส่งพิจารณา** กดได้เมื่อปรับลดวงเงินแล้วเท่านั้น
3. คลิก **ส่งพิจารณา** กรอกเหตุผล แล้วคลิก **ยืนยันส่งพิจารณา**
   หรือคลิก **ยกเลิกคำร้อง** เพื่อไม่อนุมัติ ปุ่ม **ส่งกลับแก้ไข** ไม่แสดงสำหรับคำร้องนี้

### 5.4 เบิกจ่ายเงินให้นักศึกษา

**วัตถุประสงค์:** บันทึกการโอนเงินกู้ให้นักศึกษา พร้อมสลิปหลักฐาน

**สิ่งที่ต้องมี:**

- คำร้องมีสถานะ **รอเบิกจ่ายเงิน**
- โอนเงินเข้าบัญชีของนักศึกษาแล้ว และมีไฟล์สลิป JPG, PNG หรือ PDF ขนาดไม่เกิน 10 MB

> **คำเตือน:** ตรวจสอบธนาคาร เลขที่บัญชี และชื่อบัญชีให้ตรงกับข้อมูลในคำร้องก่อนโอนเงินทุกครั้ง
> ระบบไม่มีปุ่มแก้ไขการเบิกจ่ายหลังยืนยันแล้ว

**ขั้นตอน:**

1. เปิดเมนู **เบิกจ่ายหนี้**
2. คลิก **ดำเนินการ** ที่คำร้องที่ต้องการ ระบบแสดงหน้าต่าง **ดำเนินการเบิกจ่ายเงิน**

   ![รายการเบิกจ่าย](images/user-manual-staff/admin-08-disburse-list.png)

3. ตรวจสอบ **ข้อมูลบัญชีธนาคารสำหรับรับเงิน** และ **จำนวนเงินที่อนุมัติ (บาท)**
   คลิก **คัดลอก** ข้างเลขที่บัญชีเพื่อคัดลอกเลขบัญชีไปใช้ในแอปธนาคาร

   ![ดำเนินการเบิกจ่ายเงิน](images/user-manual-staff/admin-09-disburse-top.png)

4. โอนเงินจากบัญชีของกองทุนเข้าบัญชีของนักศึกษา
5. ที่ **แนบสลิปหลักฐานการโอนเงิน** คลิก **คลิกเพื่ออัปโหลดสลิปโอนเงิน** แล้วเลือกไฟล์สลิป
   คลิก **ดูตัวอย่าง** เพื่อตรวจสอบรูป หรือ **เปลี่ยนรูปภาพ** เพื่อเลือกไฟล์ใหม่
6. คลิก **ยืนยันว่าโอนเงินแล้ว**

   ![แนบสลิปและยืนยันการโอน](images/user-manual-staff/admin-10-disburse-upload.png)

**ผลลัพธ์:** สถานะคำร้องเป็น **โอนเงินแล้ว** ระบบส่งอีเมลแจ้งนักศึกษา และบันทึกรายการจ่ายในบัญชีกองทุน
คำร้องแสดงปุ่ม **ดูหลักฐาน** เพื่อเปิดสลิปที่แนบไว้

> **หมายเหตุ:**
> - ปุ่ม **ยกเลิกคำร้อง** ในหน้าต่างนี้ปิดหน้าต่างเท่านั้น ไม่ยกเลิกคำร้อง และไม่บันทึกข้อมูลใด
> - ข้อความใต้ช่องอัปโหลดเขียนว่า **รองรับ JPG หรือ PNG(ขนาดไม่เกิน 500 KB)** แต่ระบบรับไฟล์ JPG, PNG และ PDF ขนาดไม่เกิน 10 MB

### 5.5 ตรวจสอบสลิปชำระเงินคืน

**วัตถุประสงค์:** ยืนยันหรือปฏิเสธหลักฐานการชำระเงินคืนที่นักศึกษาส่งมา

**ขั้นตอน:**

1. เปิดเมนู **ตรวจสอบสลิปชำระเงิน** แล้วคลิก **ตรวจสอบ** ที่คำร้องที่ต้องการ

   ![ตรวจสอบสลิปชำระเงิน](images/user-manual-staff/admin-12-verify-list.png)

2. ระบบแสดง **ตรวจสอบการชำระเงิน** พร้อมตาราง **กำหนดการและประวัติการชำระเงิน**
   ตารางแสดงทุกงวด ทุกครั้งที่ส่ง ยอดเรียกเก็บ ยอดที่ชำระ และสถานะของสลิป
3. คลิกปุ่มสถานะ **รอตรวจสอบ** ของสลิปที่ต้องการตรวจ

   ![กำหนดการและประวัติการชำระเงิน](images/user-manual-staff/admin-13-payment-table.png)

4. ในหน้าต่าง **ตรวจสอบสลิปชำระเงิน** เทียบ **ยอดเงินที่โอนมา**, **วันที่โอน** และ **เวลาที่โอน**
   กับรูปสลิป คลิกรูปสลิปเพื่อดูภาพขนาดเต็ม

   ![ตรวจสอบสลิปชำระเงิน](images/user-manual-staff/admin-14-slip-review.png)

5. ทำอย่างใดอย่างหนึ่ง
   - สลิปถูกต้อง: คลิก **อนุมัติสลิป ถูกต้อง** แล้วคลิก **ยืนยัน**
   - สลิปไม่ถูกต้อง: คลิก **ปฏิเสธสลิป** กรอก **เหตุผลที่ปฏิเสธสลิป** แล้วคลิก **ยืนยัน**
     นักศึกษาเห็นเหตุผลนี้ในอีเมลและในหน้าประวัติหลักฐานการชำระ

   ![อนุมัติสลิป](images/user-manual-staff/admin-17-slip-approve.png)

   ![ปฏิเสธสลิป](images/user-manual-staff/admin-16-slip-reject.png)

**ผลลัพธ์:** ตารางแสดงสลิปเป็น **ตรวจสอบแล้ว** หรือ **ไม่อนุมัติ** และยอดที่ชำระของงวดนั้น
ระบบส่งอีเมลแจ้งผลให้นักศึกษา เมื่อชำระครบทุกงวด สถานะคำร้องเป็น **เสร็จสิ้น**

![ผลหลังอนุมัติสลิป](images/user-manual-staff/admin-18-slip-done.png)

> **คำเตือน:** ถ้าระบบแสดง **รายการนี้มียอดโอนเกินยอดหนี้คงค้างทั้งหมด** ปุ่มปฏิเสธจะเป็น
> **ปฏิเสธสลิป · ติดต่อนักศึกษา** ให้ติดต่อนักศึกษาเพื่อคืนเงินส่วนเกินก่อนปิดรายการ

## 6. ผู้บริหาร

### 6.1 หน้าหลัก: รายงานและสถิติทางการเงิน

หน้าหลักแสดง **เงินทั้งหมดในระบบ**, **เงินคงเหลือในระบบ**, **เงินที่ค้างชำระทั้งหมด**,
**สัดส่วนเงินในระบบ**, ยอดการกู้ยืมและการคืนเงินรายเดือน และจำนวนคำร้องรายเดือน
เลือกปีที่ต้องการดูได้ที่ตัวเลือกปีมุมขวาของแต่ละกราฟ

![หน้าหลักของผู้บริหาร](images/user-manual-staff/exec-01-dashboard.png)

### 6.2 อนุมัติคำร้องขั้นสุดท้าย

**สิ่งที่ต้องมี:** คำร้องมีสถานะ **รอผู้บริหารอนุมัติ**

**ขั้นตอน:**

1. เปิดเมนู **คำร้องรอพิจารณา โดยผู้บริหาร** แท็บ **รออนุมัติ** แสดงคำร้องที่รอท่าน

   ![คำร้องรอพิจารณาโดยผู้บริหาร](images/user-manual-staff/exec-03-pending-executive.png)

2. คลิก **ตรวจสอบ** แล้วตรวจสอบข้อมูลคำร้อง ความเห็นของอาจารย์และเจ้าหน้าที่แสดงใน **ติดตามสถานะคำร้อง**

   ![รายละเอียดคำร้องสำหรับผู้บริหาร](images/user-manual-staff/exec-04-review-top.png)

3. คลิกปุ่มผลการพิจารณา
   - **อนุมัติ**: คำร้องมีสถานะ **รอเบิกจ่ายเงิน** และไปที่เจ้าหน้าที่เพื่อโอนเงิน
   - **ส่งกลับแก้ไข**: คำร้องกลับไปที่เจ้าหน้าที่คนเดิมเพื่อปรับลดวงเงิน (หัวข้อ 5.3)
   - **ไม่อนุมัติ**: ปิดคำร้อง นักศึกษาเห็นสถานะ **ไม่อนุมัติโดยผู้บริหาร**
4. กรอกความเห็นหรือเหตุผล แล้วคลิก **ยืนยันอนุมัติ**, **ยืนยันส่งกลับแก้ไข** หรือ **ยืนยันไม่อนุมัติ**

   ![ยืนยันอนุมัติ](images/user-manual-staff/exec-07-approve-confirm.png)

   ![ส่งกลับแก้ไขให้เจ้าหน้าที่](images/user-manual-staff/exec-05-return-confirm.png)

   ![ไม่อนุมัติ](images/user-manual-staff/exec-06-reject-confirm.png)

**ผลลัพธ์:** ระบบแสดง **ดำเนินการคำร้องเสร็จสิ้น** คลิก **เสร็จสิ้น**

![ดำเนินการคำร้องเสร็จสิ้น](images/user-manual-staff/exec-08-done.png)

> **หมายเหตุ:** เมื่อกด **ส่งกลับแก้ไข** ช่องความเห็นเขียนว่า **ระบุสิ่งที่ต้องการให้นักศึกษาแก้ไข**
> แต่คำร้องไปที่เจ้าหน้าที่ ไม่ไปที่นักศึกษา ให้เขียนความเห็นถึงเจ้าหน้าที่

### 6.3 คำร้องในฐานะอาจารย์ที่ปรึกษา

ผู้บริหารที่เป็นอาจารย์ที่ปรึกษาของนักศึกษาด้วย พิจารณาคำร้องของนักศึกษาในความดูแลได้ที่เมนู
**คำร้องรอพิจารณา โดยอาจารย์ที่ปรึกษา** หน้านี้แสดงเฉพาะคำร้องที่ท่านเป็นอาจารย์ที่ปรึกษา
ขั้นตอนเหมือนหัวข้อ 4.2

![คำร้องรอพิจารณาในฐานะอาจารย์ที่ปรึกษา](images/user-manual-staff/exec-02-pending-advisor.png)

### 6.4 ข้อมูลนักศึกษาทั้งหมด

เมนู **นักศึกษาในความดูแล** ของผู้บริหารเปิดหน้า **ข้อมูลนักศึกษาทั้งหมด**
หน้านี้แสดงนักศึกษาทุกคนที่มีคำร้อง พร้อมสถานะคำร้องและหนี้คงเหลือ

1. กรองด้วยแท็บ **ทั้งหมด**, **มีคำร้องดำเนินการ**, **มีหนี้คงเหลือ**, **ชำระครบ** หรือ **เคยชำระล่าช้า**
2. คลิกชื่อนักศึกษาเพื่อดู **ประวัติหลักฐานการชำระเงิน**

![ข้อมูลนักศึกษาทั้งหมด](images/user-manual-staff/exec-09-students.png)

| กรุณาระบุสิ่งที่ต้องการให้นักศึกษาแก้ไข | กดยืนยันส่งกลับแก้ไขโดยไม่กรอกความเห็น | กรอกสิ่งที่ต้องแก้ไข |
| กรุณาระบุเหตุผลที่ไม่อนุมัติ / กรุณาระบุเหตุผลในการยกเลิกคำร้อง | กดยืนยันไม่อนุมัติโดยไม่กรอกเหตุผล | กรอกเหตุผล |

| กรุณาระบุวงเงินที่มากกว่า 0 บาท | วงเงินใหม่เป็น 0 หรือว่าง | กรอกวงเงินใหม่ |
| ไม่สามารถปรับวงเงินมากกว่าที่ขอได้ (สูงสุด ...) | วงเงินใหม่มากกว่าจำนวนที่นักศึกษาขอ | กรอกวงเงินไม่เกินจำนวนที่ขอ |
| ไม่สามารถระบุวงเงินเกินวงเงินระบบ (สูงสุด ...) | วงเงินใหม่เกินวงเงินสูงสุดของระบบ | กรอกวงเงินไม่เกินวงเงินระบบ |

| คำร้องนี้ถูกดำเนินการไปแล้ว หรือเกิดข้อขัดแย้ง | เจ้าหน้าที่อื่นเบิกจ่ายคำร้องนี้ไปก่อน | โหลดหน้าใหม่ แล้วตรวจสอบสถานะ |
| ไฟล์สลิปไม่ถูกต้อง | ไฟล์สลิปเบิกจ่ายไม่ใช่ JPG, PNG หรือ PDF หรือใหญ่เกิน 10 MB | เลือกไฟล์ใหม่ |
| ไม่พบข้อมูลคำร้องนี้ในระบบ | คำร้องถูกลบหรือไม่อยู่ในสิทธิ์ของท่าน | โหลดหน้าใหม่ |

| เกิดข้อผิดพลาดในการบันทึกข้อมูล / เกิดข้อผิดพลาดในการส่งข้อมูล | ข้อผิดพลาดอื่น | ลองใหม่ หากยังไม่ได้ แจ้งผู้ดูแลระบบ |
