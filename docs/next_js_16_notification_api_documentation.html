1. ข้อมูลการเชื่อมต่อ API (Endpoint Specs)

โครงสร้าง API และพารามิเตอร์ที่รองรับ

POST
Headers Authorization Content-Type: application/json Authorization: Bearer <YOUR_TOKEN>

รายละเอียดพารามิเตอร์ใน Request Body

Parameter Type Required คำอธิบาย ตัวอย่าง
program String จำเป็น ชื่อหัวข้อหรือชื่อโปรแกรมที่ต้องการส่ง "ทดสอบระบบ"
email String จำเป็น อีเมลผู้รับการแจ้งเตือน "test@cmu.ac.th"
message String จำเป็น ข้อความรายละเอียดแจ้งเตือน "สวัสดีครับ"
weblink String จำเป็น ลิงก์ URL ที่ต้องการแนบปลายทาง "https://google.com"
color String จำเป็น โค้ดสี HEX สำหรับตกแต่งการแสดงผล "#1CD2A3"
Sample Request Payload
JSON (Request Body) 
{
  "program": "ทดสอบระบบ",
  "email": "test@cmu.ac.th",
  "message": "สวัสดีครับ",
  "weblink": "https://google.com",
  "color": "#1CD2A3"
}
Success Response Payload (200 OK)
JSON (Response) 
{
  "data": "Success"
}

2. ตั้งค่าการซ่อน Token (.env.local)

เพื่อความปลอดภัยในการเก็บ Bearer Token ไม่ให้รั่วไหลไปยังฝั่ง Client Browser

สร้างไฟล์ชื่อ .env.local ไว้ที่ Root Directory ของโปรเจกต์ Next.js 16:

.env.local 
NOTIFY_API_TOKEN=your_secret_bearer_token_here

3. วิธีที่ 1: เรียกผ่าน Server Action (แนะนำสำหรับ Next.js 16)

ยิง API โดยตรงจากเซิร์ฟเวอร์ด้วย `use server` ใน App Router

Recommended

1 สร้าง Server Action File (`app/actions/notify.ts`)

app/actions/notify.ts 
'use server';

export interface NotifyPayload {
  program: string;
  email: string;
  message: string;
  weblink: string;
  color: string;
}

export async function sendNotificationAction(payload: NotifyPayload) {
  try {
    const response = await fetch('https://test.com/notify', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${process.env.NOTIFY_API_TOKEN}`,
      },
      body: JSON.stringify(payload),
    });

    const data = await response.json();

    if (!response.ok) {
      return { success: false, error: 'ส่งการแจ้งเตือนไม่สำเร็จ' };
    }

    // ตรวจสอบ Response payload ว่าเป็น { "data": "Success" } หรือไม่
    return { success: true, data };
  } catch (error) {
    console.error('Server Action Error:', error);
    return { success: false, error: 'เกิดข้อผิดพลาดในการเชื่อมต่อเซิร์ฟเวอร์' };
  }
}

2 การเรียกใช้งานใน Client Component (`app/page.tsx`)

app/page.tsx 
'use client';

import { useState } from 'react';
import { sendNotificationAction } from '@/app/actions/notify';

export default function NotificationPage() {
  const [loading, setLoading] = useState(false);
  const [status, setStatus] = useState<string | null>(null);

  const handleSend = async () => {
    setLoading(true);
    setStatus(null);

    const result = await sendNotificationAction({
      program: 'ทดสอบระบบ',
      email: 'test@cmu.ac.th',
      message: 'สวัสดีครับ ส่งข้อความจาก Server Action',
      weblink: 'https://google.com',
      color: '#1CD2A3',
    });

    setLoading(false);

    if (result.success && result.data?.data === 'Success') {
      setStatus('ส่งการแจ้งเตือนสำเร็จ! (Response: "Success")');
    } else {
      setStatus('เกิดข้อผิดพลาด: ' + (result.error || 'ส่งข้อมูลไม่สำเร็จ'));
    }
  };

  return (
    <div class="p-6 space-y-4">
      <button 
        onClick={handleSend}
        disabled={loading}
        className="bg-emerald-600 hover:bg-emerald-700 text-white font-medium px-4 py-2 rounded-lg transition-all disabled:opacity-50"
      >
        {loading ? 'กำลังส่ง...' : 'ส่งแจ้งเตือน (Server Action)'}
      </button>
      {status && <p class="text-sm text-slate-700 font-medium">{status}</p>}
    </div>
  );
}

4. วิธีที่ 2: เรียกผ่าน Internal API Route (`/api/notify`)

สร้าง Route Handler เพื่อรับ REST API Request จากฝั่ง Client

1 สร้าง Route Handler File (`app/api/notify/route.ts`)

app/api/notify/route.ts 
import { NextResponse } from 'next/server';

export async function POST(request: Request) {
  try {
    const body = await request.json();

    const response = await fetch('https://test.com/notify', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${process.env.NOTIFY_API_TOKEN}`,
      },
      body: JSON.stringify({
        program: body.program,
        email: body.email,
        message: body.message,
        weblink: body.weblink,
        color: body.color,
      }),
    });

    const data = await response.json();

    return NextResponse.json(data, { status: response.status });
  } catch (error) {
    console.error('API Route Error:', error);
    return NextResponse.json(
      { error: 'เกิดข้อผิดพลาดภายในเซิร์ฟเวอร์' },
      { status: 500 }
    );
  }
}

2 การยิงเรียกใช้งานผ่าน Client (`fetch`)

app/page.tsx 
'use client';

import { useState } from 'react';

export default function ApiRouteDemoPage() {
  const [responseMsg, setResponseMsg] = useState<string | null>(null);

  const handleSendViaApi = async () => {
    try {
      const response = await fetch('/api/notify', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({
          program: 'ทดสอบระบบ',
          email: 'test@cmu.ac.th',
          message: 'สวัสดีครับ ส่งข้อความผ่าน Route Handler (/api/notify)',
          weblink: 'https://google.com',
          color: '#1CD2A3',
        }),
      });

      const result = await response.json();

      if (response.ok && result.data === 'Success') {
        setResponseMsg('ส่งการแจ้งเตือนสำเร็จ! (Response: "Success")');
      } else {
        setResponseMsg('เกิดข้อผิดพลาด: ' + (result.error || 'ส่งข้อมูลไม่สำเร็จ'));
      }
    } catch (err) {
      console.error(err);
      setResponseMsg('เกิดข้อผิดพลาดในการเชื่อมต่อ');
    }
  };

  return (
    <div class="p-6 space-y-4">
      <button 
        onClick={handleSendViaApi}
        className="bg-blue-600 hover:bg-blue-700 text-white font-medium px-4 py-2 rounded-lg transition-all"
      >
        ส่งแจ้งเตือน (API Route)
      </button>
      {responseMsg && <p class="text-sm text-slate-700 font-medium">{responseMsg}</p>}
    </div>
  );
}
